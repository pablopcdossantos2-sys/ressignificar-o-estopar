# Ressignificar o Estopar

Web-portfólio/manual educativo sobre psicologia aplicada ao ato de estopar no trading.

## Objetivo

Ajudar traders a ressignificar o stop: de símbolo de fracasso para ferramenta profissional de gestão de risco e execução de um plano probabilístico.

O projeto combina educação sobre vieses comportamentais com ferramentas inspiradas em TCC, ACT, regulação emocional, intenções de implementação e princípios de aprendizagem.

## Conteúdo

- `index.html` — página inicial;
- `manual.html` — manual com 9 artigos;
- `ferramentas.html` — exercícios interativos que funcionam localmente no navegador;
- `referencias.html` — bibliografia comentada;
- `assets/styles.css` — identidade visual e responsividade;
- `assets/app.js` — busca, tema, progresso e ferramentas locais.

## Como visualizar

Abra `index.html` no navegador ou publique a raiz do repositório com GitHub Pages.

## Escopo e limites

Este projeto é educativo. Não substitui psicoterapia, avaliação psicológica ou atendimento médico, e não constitui recomendação financeira. As ferramentas são adaptações educacionais de conceitos psicológicos; quando um método clínico é citado, sua aplicação ao trading é explicitamente tratada como uma adaptação, não como tratamento.

## Referências

Cada artigo contém links para a bibliografia do projeto. A página `referencias.html` reúne as fontes e seus DOI/URLs para consulta.
